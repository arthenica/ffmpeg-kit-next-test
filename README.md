# FFmpegKitNext Test

Test applications for [FFmpegKitNext](https://github.com/arthenica/ffmpeg-kit-next).

- `Android` under the [android](https://github.com/arthenica/ffmpeg-kit-next-test/tree/main/android) folder
- `Flutter` under the [flutter](https://github.com/arthenica/ffmpeg-kit-next-test/tree/main/flutter) folder
- `iOS` under the [ios](https://github.com/arthenica/ffmpeg-kit-next-test/tree/main/ios) folder
- `Linux` under the [linux](https://github.com/arthenica/ffmpeg-kit-next-test/tree/main/linux) folder
- `macOS` under the [macos](https://github.com/arthenica/ffmpeg-kit-next-test/tree/main/macos) folder
- `React Native` under the [react-native](https://github.com/arthenica/ffmpeg-kit-next-test/tree/main/react-native) folder
- `tvOS` under the [tvos](https://github.com/arthenica/ffmpeg-kit-next-test/tree/main/tvos) folder

All applications are identical and support command execution, video encoding, accessing https urls, encoding audio,
burning subtitles, video stabilisation, pipe operations, concurrent command execution and using ffkit protocols.

Android test applications (including Flutter and React Native apps running on Android) also include the ffkitsaf
protocol under the FFKit Protocols page to demonstrate how SAF URIs can be used with `FFmpegKitNext`.
